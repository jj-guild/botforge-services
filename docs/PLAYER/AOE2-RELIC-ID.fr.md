# Trouver ton Relic ID (AoE2)

Le bot identifie ton compte de deux façons :

1. **Ton pseudo en jeu** (exact, sensible à la casse) — le bot cherche
   les profils correspondants et te propose les homonymes avec clan,
   pays et Elo pour choisir.
2. **Ton Relic ID** — l'identifiant numérique unique de ton compte
   (ex. `17190369`).

## Où trouver ton Relic ID

Sur **[aoe2insights.com](https://www.aoe2insights.com)**, connecte-toi
avec ton compte Steam et ouvre ton profil. **Sous ton avatar**, ton
Relic ID est affiché avec deux icônes à droite :

```text
# 17190369 [⧉]
```

- Le `#` indique qu'il s'agit d'un identifiant.
- Le nombre (`17190369`) est ton **Relic ID**.
- Le bouton **copier** (à droite) le met dans ton presse-papiers.

Clique sur l'id affiché, puis sur l'icône de copie, et colle-le dans le
champ « Ton pseudo en jeu ou ton Relic ID » du formulaire d'ajout de
compte.

> **Note** — l'identifiant visible dans l'URL de ta page
> (`/user/12488557/`) est l'id *interne* aoe2insights, PAS ton Relic
> ID. Les URL aoe2insights ne sont plus acceptées par le bot (le site
> bloque nos requêtes serveur) : utilise toujours le nombre sous ton
> avatar.
